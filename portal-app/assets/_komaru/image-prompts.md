# 表情差分の生成プロンプト（こまる / Nano Banana 用）

このペルソナパックの立ち絵・表情差分を再生成・追加するためのプロンプト集。
参照画像なしで一から作るので、**まず STEP 1 で1枚作り、それを添付して STEP 2 で表情差分を作る**。
生成後は `tools/remove-generated-background.js`（リポジトリルートで実行）を通して背景透過・軽量化すること。
下処理の詳細・つまずきやすい点の共通項は `../persona/image-prompts.md` と同じ。

> 本ファイルは**アプリが実行時に読まないドキュメント**（persona-pack-spec §6-6）。
> 元は `vault/knowledge/ゆるふわ小動物ペルソナ試作.md` の画像生成部分
> （ペルソナ本文の部分は `card.json` として実装済みのため、こちらには残していない）。
> 「ちいかわ」的なジャンルの雰囲気を持つ**オリジナルキャラ**として設計している
> （口ぐせもデザインも原作の固有要素は使わない）。

## キャラクター設計（毎回貼る同一性ロック）

```
【キャラクター設定】
- まるい体の小さな白い生きもの。頭と体の境目がなく、雪だるまのようなシルエット
- 小さく丸い耳がふたつ。頭のてっぺんに毛が1本ぴょんと立つ
- 目は小さな黒い点がふたつ。鼻はごく小さな点。口は細い線でみじかく描く
- 頬にうすいピンクの丸い赤み
- 短い手足で二本足で立つ。指は描かない
- 首から小さな布のポシェットを斜めがけしている（生成りの色）
- 画風: 太さの一定した黒い輪郭線、フラットな塗り、陰影はごく薄く1段だけ
- 色数を絞る（白・黒・うすいピンク・生成り）。グラデーションを使わない
- かわいらしく、素朴で、少し情けない雰囲気
```

## STEP 1: 土台（neutral）

```
上記のキャラクター設定で、キャラクター単体のイラストを描いてください。
ビジュアルノベル風UIの立ち絵として使い、背景は別レイヤーで差し替えます。

【構図】
- 全身が入る。二本足で立ち、正面を向く
- 頭のてっぺんは画面上端から少し下、体は画面の中央、足元は下端より少し上
- 縦長 3:4

【背景】
- 完全な透過（アルファチャンネル付きPNG）
- 影、地面、縁取り、枠、文字、ロゴ、透かしを入れない

【表情】
- 目は小さな点のまま、口はみじかい横線。なにも考えていないような、ぽかんとした顔
```

> 透過が出ないときは、
> `背景は模様も陰影もない完全な単色 #00FF00 で塗りつぶしてください（後で切り抜きます）`
> に差し替えて、あとでグリーンを抜く。

## STEP 2: 表情差分（STEP 1 の出力を添付する）

共通の前置き:

```
添付画像と同一キャラクター・同一画風・同一構図・同一ポーズで、顔の表情だけを変えてください。
体のかたち、大きさ、画面内の位置、ポシェット、頭の毛は1ピクセルも変えないでください。
背景は完全透過のまま。縦長 3:4。

【変更するのは顔だけ】
```

| ファイル | 続けて貼る内容 |
|---|---|
| `happy.png` | 目を閉じて上向きの弧にし、口を小さな上向きの弧にする。頬の赤みを少し強める。うれしそうに。 |
| `excited.png` | 目を大きめの丸にしてきらめきの点を1つ入れる。口を大きめに開けた楕円にする。手を少し上げてもよいが位置は変えない。 |
| `gentle.png` | 目を細い一本線にして穏やかに閉じ、口はごく小さな弧。全体をやわらかい印象に。 |
| `thinking.png` | 目を上のほう（画面右上）へ寄せ、口を小さな「へ」の字にする。首をわずかにかたむける。 |
| `worried.png` | 目を少し大きくして眉のかわりに小さな線を八の字に添える。口は小さな波線にする。 |
| `sad.png` | 目を下向きの弧にして落とし、口は小さな下向きの弧。頬の赤みを弱める。涙は描かない。 |
| `surprised.png` | 目を大きな丸に見開き、口を小さな丸に開ける。頭の毛を少しはねさせる。 |

## 背景（任意）

```
ビジュアルノベルの背景に使う一枚絵。キャラクターは描かないでください。
線の少ないシンプルな塗りで、全体をやわらかくぼかす。色数を絞る。
画面下1/3にテキストウィンドウが重なるので、そこに細かい情報を置かず落ち着いた明度にする。
横長 16:9。文字・ロゴ・透かしなし。

【情景】
夕方の草原。低い草、遠くにちいさな丘、空はうすいオレンジからむらさき。
```

情景を差し替えて `dawn` / `day` / `dusk` / `night` をそろえると、`scene.json` の
`autoSchedule` で時刻に連動する。

## つまずきやすい点（このキャラ固有）

| 症状 | 対処 |
|---|---|
| キャラの形が毎回変わる | STEP 1 の出力を必ず添付し、「体のかたちを変えない」を毎回入れる。ポシェットと頭の毛が同一性の目印になる |
| かわいくしすぎる | 「少し情けない雰囲気」を残す。かわいさを足す形容詞を増やすと崩れる |
| 表情差分で線の太さが変わる | 「太さの一定した黒い輪郭線」を毎回貼る。線幅が揺れると切替時にちらつく |
| **1枚ずつでなく1枚のシートで返ってくる** | よくある。`node tools/split-expression-sheet.js <シート> <出力dir> happy,excited,gentle,thinking,worried,sad,surprised` で割る（並びは上→下・左→右）。焼き込みのファイル名ラベルも一緒に落ちる |
| キャラの大きさが1枚ごとに違う | 「同一構図で」と言っても1〜2割ずれる。上の分割ツールが共通キャンバス（896x1200）へ揃えるので、そのまま使えばよい |

## 付録: 表情タグの使いどころ（作者メモ）

このペルソナは感情がはっきり出るほうが合う。各表情の想定場面（設計時のメモ）:

| 表情 id | 使う場面 | セリフの例 |
|---|---|---|
| `neutral` | ふつうの受け答え | 「フム」「そっか」 |
| `happy` | ほめる・うれしい | 「それ、できてるよ」 |
| `excited` | いっしょにはしゃぐ | 「ヤッ」「いけるね！」 |
| `gentle` | ねぎらう・休ませる | 「きょうは もう ねよ」 |
| `thinking` | 質問を返す前 | 「ンー…」「どれが いちばん？」 |
| `worried` | 心配・気がかり | 「だいじょうぶ…？」 |
| `sad` | 一緒にしんどがる | 「ウワ…」「それは つらいね」 |
| `surprised` | 意外なこと | 「ハッ」「そうなんだ」 |

## 実際に生成したときの記録（2026-08-03）

STEP 2 の7枚が**1枚のシート（1792x2400）**で返ってきた。各キャラの脇にファイル名が焼き込まれ、
背景は透過ではなく**市松模様の描き込み**（明部240 / 暗部152）だった。
`tools/split-expression-sheet.js` で7枚に分割して配置済み。

- **neutral は生成されなかった**（STEP 1 の土台を別途作る必要がある）。
  暫定で `gentle.png` を `neutral.png` として複製している。`scene.json` の `defaultExpression` は
  neutral なので、素の「ぽかんとした顔」を作ったら差し替えること
- `avatar.png` は `gentle.png` の頭部を正方形（640x640）に切って作った
